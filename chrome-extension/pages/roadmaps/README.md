# Roadmaps Workspace

Roadmaps organize learning or delivery sequences into a structured path.

## Main capabilities

- Create and edit Roadmaps.
- Organize milestones and sequences.
- Connect Roadmaps with Learning cards.
- Open related records.
- Import/export JSON.
- Download/import Markdown where supported.
