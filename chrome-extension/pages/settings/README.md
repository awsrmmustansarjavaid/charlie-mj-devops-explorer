# Settings Workspace

Settings controls repository sources, documentation sources, themes, health behavior, and configuration portability.

## Main capabilities

- Configure repository URL and branch.
- Configure raw GitHub paths.
- Configure technology/category JSON sources.
- Configure Official Documentation JSON.
- Configure theme and accent.
- Import/export configuration.
- Reset configuration.
