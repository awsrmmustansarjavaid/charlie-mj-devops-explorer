# Learning Workspace

The Learning page is the central knowledge workspace. It turns resources and technologies into structured Learning cards and connects them with official documentation, Labs, Projects, Goals, and Roadmaps.

## Main capabilities

- Create, edit, open, and delete Learning cards.
- Search saved resources and technologies.
- Select one or more official documentation records.
- Add Medium, LinkedIn, YouTube, blog, course, and custom resources.
- Track difficulty, status, notes, tags, and progress.
- Link existing Labs, Projects, Goals, and Roadmaps.
- Remove, edit, or open linked records.
- Import/export JSON and Markdown where supported.
