# Charlie MJ DevOps Explorer Data Layer

The extension uses the configured GitHub repository's live `data/devops-categories.json` and `data/devops-technologies.json` as the primary taxonomy source.

This directory contains maintainable local seed/schema databases for the richer architecture:

- `devops-services.json` — provider → domain → category → service examples
- `devops-documentation.json` — official website/docs/GitHub mappings
- `devops-roadmaps.json` — starter roadmap node sets
- `devops-tags.json` — tag vocabulary
- `devops-resources.json` — starter resources

Personal data such as custom categories, learning, roadmap edits, labs, projects, collections, scripts, activity and My Stack stays in Chrome local storage.
