# 🚀 What Is Charlie MJ DevOps Explorer?

**Charlie MJ DevOps Explorer** is a frontend web application designed to make discovering DevOps-related GitHub repositories easier and more organized.

Instead of repeatedly searching GitHub for individual technologies, tools, platforms, and DevOps concepts, the Explorer provides a dedicated interface for discovering repositories across the modern DevOps ecosystem.

The application brings GitHub repository discovery together with categorized technologies, cloud platforms, DevOps tools, workflows, and learning resources.

It is designed for developers, DevOps engineers, cloud engineers, system administrators, students, and anyone learning or working with modern infrastructure and software delivery technologies.

# ✨ Main Features

## 🔎 GitHub Repository Search

Search GitHub directly from the main search interface to discover DevOps-related repositories.

The search system can be used to find projects, tools, technologies, tutorials, labs, documentation, and other engineering resources.

## 🏷️ Context-Aware Technology & Tag Search

Technology cards, category cards, and tags can trigger the main search engine.

When a supported card or tag is clicked, its context is placed into the main search field and the application starts the corresponding GitHub search.

For example:

```text
AWS + DevOps
→ Amazon Web Services DevOps

Version Control + Git
→ Version Control Git

CI/CD + Jenkins
→ CI/CD Jenkins

Infrastructure as Code + Terraform
→ Infrastructure as Code Terraform
```

This allows the different sections of the website to work together instead of acting as separate static lists.

## ☁️ Cloud Provider Discovery

Explore major cloud platforms and their related DevOps technologies.

# 🏗️ Project Architecture

Charlie MJ DevOps Explorer is intentionally designed as a lightweight **static frontend application**.

The application does not require:

* A backend server
* A backend database
* A custom API server

Instead, it uses:

* HTML
* CSS
* JavaScript
* Local JSON data
* GitHub REST API

The general architecture is:

```text
                    Charlie MJ DevOps Explorer
                              │
             ┌────────────────┴────────────────┐
             │                                 │
        Local Data                         GitHub API
             │                                 │
     ┌───────┴────────┐                 Repository Search
     │                │
Categories       Technologies
     │                │
     └───────┬────────┘
             │
        Search Engine
             │
             ↓
      GitHub Repository
           Results
```

# 🐙 GitHub API

The frontend uses the **public GitHub REST API** to search for repositories.

No custom backend API is required.

### Important

Do **not** place a personal GitHub access token directly inside frontend JavaScript.

The application can use unauthenticated public GitHub API requests, but GitHub applies rate limits to unauthenticated API usage.

For larger-scale usage, a backend or another appropriate API architecture may be required.

# 💻 Local Development

Because the application uses JavaScript modules and fetches local JSON files, it should be served through a local HTTP server rather than opened directly using:

```text
file://
```

## Start a Local Server

From the project directory:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000/
```

The website should now load through the local HTTP server.
