# Search

The Search screen combines the built-in catalog with an optional raw repository resource database.

## Filters

- Query
- Multiple categories
- Tags
- Type
- Difficulty
- AND mode
- OR mode

## GitHub search

**Search GitHub** calls the public GitHub repository search API. If a token is configured it is also sent as an authenticated request, which can improve rate-limit availability.

GitHub results are clearly presented as GitHub repository results and can be bookmarked.
